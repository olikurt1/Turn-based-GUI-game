##AI Takeover Game

The game featured in this repository is themed behind AI becoming physical in robotic form and having taking over the world. The player is one of the last humans left fighting against AI. 
This is a turn based combat game which means the player decides whether they want the character to dodge or attack and a hardcoded probability of such decisions being successful means the player has to strategise on what the next best move is. The enemy always attacks and has a certain probability of missing based on the type of enemy it is. The player has a chance of missing when attacking. It is a survival mode game where the key objective is to rack up the highest score possible as rooms load indefinitely unless player leaves the game. 

To run the game, this repository should be cloned into a local folder and then compiled into Java source files using javac src/*.java. This will require a Java Runtime program. Once compiled the program should be run from Main.java. This will load the start menu.

Assumptions made during this project included how the three interactive elements required were interpreted. I included combat, healing and inventory management. I assume that these three count as separate interactive elements. Initially, I had combat and healing only because I thought that difficulty and username selection could count but this doesn't really include into the experience of what the player can do when in the game. A further assumption made includes was that the game being singleplayer is enough and that providing the player with initial items at game initialisation was fair for progress. Along with this I assumed that to show scholarship, I'd implement the game into a GUI form after initially having it text based. I assumed this would be good as there was no explicit part of the brief that said the game MUST be in text based form.
